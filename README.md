Place your boss images in this folder with these exact names:
- Boss.png
- boss-ad-1.png
- boss-ad-2.png
- boss-ad-3.png
- boss-ad-4.png
- boss-ad-5.png

The game will automatically use these images for:
- Boss.png: The main boss asteroid (every 10 waves)
- boss-ad-X.png: The mini asteroids spawned by the boss when damaged
